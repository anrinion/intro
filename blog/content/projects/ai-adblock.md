title: 'Chrome extension: AI-based adblocker'
---
This was a proof of concept of an AI-based on-the-fly adblocker. It re-writes YouTube descriptions using an AI model to remove ads. Implemented as a Chrome extension, required you to provide the API key for an AI model. 

Install it from the [Chrome Web Store](https://chromewebstore.google.com/detail/youtube-description-rewri/bkifbmkpjodnagcldhlonpegnfolnlin).

GitHub: [anrinion/adblock](https://github.com/anrinion/adblock)

I wouldn't personally recommend using it (just block the whole description, it's never useful anyways), but it was a fun project to work on.
