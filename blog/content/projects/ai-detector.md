A Tampermonkey script that highlights text likely written by an AI. This is a fully offline and rather primitive script, using stereotypical and **annoying** markers of AI.

![Screenshot of highlighted text](https://github.com/anrinion/ai-detector/blob/main/screenshot.png?raw=true)

Install this script from [Greasy Fork](https://greasyfork.org/en/scripts/574901-ai-detector).  
Github page: [anrinion/ai-detector](https://github.com/anrinion/ai-detector).
